【的中率カウンター Android版】

このフォルダは、AndroidのChromeからホーム画面に追加してアプリのように使うためのWebアプリです。
APKファイルそのものではありません。HTTPSで公開するとインストールできます。

■ 使える機能
・「的中」「外れ」で回数と履歴を追加
・的中率を自動計算（スキップは計算に含めない）
・スキップは履歴に「－」で記録
・履歴は古い順に縦12個ずつ、次の列へ
・4個ごとに横線
・端末内に自動保存
・リセット

■ Androidへの追加方法
1. このフォルダ内のファイル一式を、HTTPS対応のWeb公開サービスにアップロードします。
2. 公開されたURLをAndroidのChromeで開きます。
3. Chromeのメニュー（︙）から「ホーム画面に追加」または「アプリをインストール」を選びます。
4. ホーム画面に追加された「的中率カウンター」をタップして使います。

■ 注意
・記録は使っている端末・ブラウザ内に保存されます。
・ブラウザのサイトデータを消去すると記録も消える場合があります。
・別の端末には自動同期されません。
・「リセット」を押すと全履歴が消えます。
